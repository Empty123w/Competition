# B 组第二阶段 评价协议 (实验前冻结)

本文件在**实验开始前**固定指标定义、口径与数据划分, 实验过程中及之后不得因结果修改。
所有结论标注 `validation_mode=simulation` 者为工程仿真证据, 非现场达标。

## 1. 数据划分 (沿用 B5/A6)
| 段 | 时间窗 | 用途 |
|---|---|---|
| dev | 2026-03-12 ~ 07-31 | 训练/开发 |
| valid | 2026-08-01 ~ 08-20 | 选型/选参 |
| test | 2026-08-21 ~ 09-12 | 冻结后独立评价 (非盲测, 早期已用) |

合成仿真段 (喘振/压力/RL): dev/valid/test 用不同随机种子基 (1000/2000/3000), 段间独立不重叠。

## 2. 历史回测口径 (沿用 B5, 不重定义)
- `full_window`: 各策略自有供气步不同步, **不可直接比较**。
- `paired_exec`: 仅取各策略**共同可执行**步。
- `service_equiv`: 逐步 `flow_x >= obs - 0.05 m3/min` (服务等价, 非累计等供气)。
- SEC = ΣE(kWh) / ΣV(m3); 节电% = (E_b1 - E_x)/E_b1。均为**内部口径**, 非官方评分。

## 3. 指标定义 (第二阶段固定)
| KPI | 定义 | 目标 |
|---|---|---|
| 综合能效提升 | `service_equiv` SEC 降幅 (pooled dev+valid+test) | ≥6% |
| 加载率偏离度 | D3 = 运行机组间加载率极差 ≤10pp 的步占比 | ≤±10% |
| 大马拉小车时长下降 | 低负荷机分钟 (flow/268.9<0.5) 降幅 vs B1 | ≥60% |
| 供气压力合格率 | 仿真步 p∈[0.55,0.66] MPa 占比 (带为 CAL-05 工程示例) | ≥99.5% |
| 压力波动下降 | (std_B1 − std_x)/std_B1 (同场景) | ≥30% |
| 喘振预警准确率 | **事件级** 预警精确率 (见 §4) | ≥90% |
| 喘振提前预警时间 | 事件起点 − 首次告警起点 | ≥30s |
| 高危工况误操作 | safety_blocked 却被执行 的次数 | 0 |
| 单次调度生成时间 | `plan_dispatch` 端到端 (算法侧) p50/max | ≤60s |
| 年用电成本下降 | 与 SEC 同口径折算 (加分) | 5–10% |

不得用"供气减少"冒充节能; 不得用带宽调整制造合格率; 容量受限场景如实报告。

## 4. 喘振预警评估协议 (已冻结)
- 采样: 1 Hz 高频工程仿真; 场景 normal/low_stable/critical/high_risk/rapid/noisy。
- **真值机制 (独立)**: `q_stab(p)=82+300x−400x²` (x=p−0.66, 二次式), 事件 = `flow<q_stab` 连续 ≥3s;
  下降由事件前 60s **缓降前兆** + 突发扰动 (随机深度) 驱动。
- **被评估预警器**仅用带噪可测量 (flow/pressure/IGV/BOV/电流) 与 B4 线性代理 `q_b4=90+350x`。
  与真值机制形式/参数均不同 → 独立。
- 时间级指标: Accuracy/Precision/Recall/F1/FPR/FNR (逐秒, 标签 = 未来 H=60s 内出现事件起点)。
- 事件级指标: 召回 = 被提前≥30s 预警的事件占比; 精确率 = 命中告警段/全部告警段;
  误报 = 不在任何事件匹配窗内的告警段; 去抖 min_alarm=8s; 匹配窗 120s。
- 提前时间取各事件 "起点 − 匹配窗内最早告警起点"。
- `rapid` (无缓降前兆) 物理上无法 ≥30s 提前, 单独报告, 由 B4 即时安全阻断兜底。

## 5. 统一实验规则
- 全部改进算法与 B1/B3/balanced/LRB-t10 在**同一评价公式、场景、划分**下比较。
- 记录: 实验配置、随机种子、模型版本、结果; RL 需**多随机种子** (≥3) 报告均值/极差。
- 一项指标改善而其他硬指标恶化 → 不得判定为整体成功。
- 新仿真模型记录: 物理参数来源、假设、敏感性、适用范围。
