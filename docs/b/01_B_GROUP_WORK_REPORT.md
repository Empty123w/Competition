# B 组个人工作报告

## 1. 项目背景与赛题目标
赛题为**空压站多机协同智能调度 Agent**（COSMO Code 平台）。空压站由多台离心式空压机（本数据为 4#、5# 阿特拉斯 ZH1250-6，额定 1250 kW / 268.9 m³/min / 0.66 MPa）组成，为产线提供压缩空气。人工调度依赖经验，易出现"大马拉小车"（大机低负载）、频繁加卸载与能效偏低。
官方关键指标（`赛题详情.docx`）：系统综合能效提升 **≥6%**、加载率偏离度 **≤±10%**（当前 ±20%）、供气压力合格率 **≥99.5%**（当前 95%）、单次调度方案 **≤60 秒**；加分项含"大马拉小车"时长下降 **≥60%**、压力波动下降 **≥30%**、喘振预警准确率 ≥90%。

## 2. B 组职责与分工
- **B 组**：把 A 提供的**预测**与**健康**结果，转换为**可解释、可检验的机组调度方案**，并评估**喘振与供气风险**，形成与人工基线**公平可比**的结果；对 C 交付可调用的 Python 函数/契约，对 D 交付带来源标签的图表数据与场景。
- **A 组**：数据治理、负荷预测、健康/RUL；向 B 交付滚动校准预测与真实健康序列（`artifacts/handoff_b/`）。
- **C 组**：Agent 编排、MCP 服务、控制指令（B 只提供仿真候选，不下发 PLC）。
- **D 组**：前端可视化与比赛材料。

## 4. 各要素之间的关系
```
A 预测(需求/区间) + A 健康  ─┐
                            ▼
        B2 功率模型(能效)   →  B3 组合枚举+负荷分配  →  B4 喘振/安全校验  →  C 契约/回退
                            ▲
        B1 人工规则基线与优化在 B5 同工况回测中公平对比（同一预测/约束/初值/时长）
```
- **B1** 是公平对照的基线（也用于优化失败时的安全回退）。
- **B2** 提供"供气→功率"的能效度量（SEC），是优化的目标函数与 KPI 的计算依据。
- **B3** 在硬约束下最小化能耗并权衡低负荷。
- **B4** 对候选做喘振代理评估与阻断；高风险/未知不得默认低风险。
- **B5** 只按同口径比较，剔除不可行步、区分"执行/阻断/不可行"，不把少供气计为节能。

## 5. 技术演进（初始方案 → 最终 LRB-t10）
1. **B3 能效优先**（`optimize_dispatch`）：枚举 4#/5# 组合 + 组合内最小功率分配 → 综合能效最高，但"大马拉小车"改善有限（全历史 ~48%）。
2. **bal 低负荷优先**（`UCConfig(balanced=True)`）：需求允许时强制每台 ≥0.5×额定，消除可再平衡低负荷 → 低负荷降幅 ~77%，SEC 略降。
3. **SBD（选择性均衡）/ EAB（能量感知均衡）**：按"每步额外能耗"阈值在 B3 与 bal 间切换 → 实测与 bal/B3 端点重合，**未产出中间点**（成本双峰：均衡生效时恒 ~6.75 kWh/步）。
4. **LRB（负荷均衡，`spread_balance`+`spread_tol`）**：约束机组间加载率差 |λ4−λ5|≤tol，容差内取最小功率 → **D3 加载率 ≈100%**，且 SEC/低负荷仍达标。
5. **闭环仿真**（`simulation/closed_loop.py`）：独立用气需求 + 储气质量平衡 + 压力 PI + BOV + 执行延迟/故障，用于压力 KPI 的工程场景验证。
6. **质量守恒修复**：显式记账安全泄压/未满足缺口，残差由异常修正为 ≈0。

## 6. 主要实现成果
- 算法：B1 规则、B2 功率/压力模型、B3 优化器、bal、LRB-t10、SBD/EAB（研究）。
- 安全：B4 代理喘振边界与阻断、过渡供气可行性、最短开停锁。
- 接口：`dispatch_api.plan_dispatch`（b3/balanced/load_balanced）+ `b_api` 稳定导出。
- 回测：dev/valid/test 三段 + 全历史统一汇总；闭环仿真 5 场景。
- 测试：优化/安全/仿真等 **328 passed**（含 B01–B20 20 项）。

## 7. 最终实验结果（内部口径）
| 策略 | 全历史 SEC 降%（服务等价） | 大马拉小车降%（paired） | D3 达标率 |
|---|---|---|---|
| LRB-t10 | 6.39 | 61.8 | ≈100% |
| bal | 7.50 | 77.2 | 2–30% |
| B3 | 7.71 | 48.3 | 0–11% |
valid/test 单段服务等价 SEC 为 3.57% / 3.04%（窄幅高负荷工况，未达 6%）。

## 8. 已解决的工程问题
- 评价口径：区分 executed/blocked/infeasible；剔除幽灵能耗（planned-but-blocked）；同供气归一。
- 数据来源核查：A6 dev/valid 划分与无泄漏；test 数据与滚动预测生成；压力建模缺字段确认。
- 加载率：D1 结构性不可行边界；D3 由 LRB 达成。
- 质量守恒：显式记账，闭合残差。

## 9. 尚存限制
- 官方未给能效公式/人工基线、加载率定义、压力合格带 → 不能宣称官方得分。
- 缺独立用气需求、储气容积、放空气量、真实喘振标签（1min 分辨率）→ 压力合格率与喘振真实准确率不可验证。
- C 端到端时延与 PLC 链路需 C 集成。

## 10. 本人工作在完整 Agent 系统中的作用
B 组是"感知（A）→ **决策（B）** → 执行（C）→ 展示（D）"闭环中的**决策核心**：把预测与健康转成满足安全约束、可解释、可回测的机组调度方案；向上为 C 提供契约化调用与安全回退，向下为 D 提供可复现的场景与指标数据。
