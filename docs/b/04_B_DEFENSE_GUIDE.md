# B 组比赛答辩手册

## 1. 一分钟个人介绍
我负责空压站智能调度 Agent 的**决策与安全模块（B 组）**：建立人工调度基线（B1）、机组功率/管网模型（B2）、多机组合优化调度（B3）、喘振风险代理与安全约束（B4）、同工况公平回测（B5），并封装为可被 C 调用的接口（B6）与两个演示场景（B7）。最终主方案 LRB-t10 在**全历史**实现综合能效改善 **6.39%**（服务等价口径）与"大马拉小车"时长下降 **61.8%**，机组间加载率达标率 **≈100%**，单次求解 **毫秒级**。

## 2. 三分钟核心技术讲解
- **问题**：多台离心机为波动负荷供气，人工调度易"大马拉小车"、能效低。
- **方法**：在硬约束（容量/5% 备用/最低稳定流量/最短开停/压力安全/喘振）内，枚举机组组合并在组合内做连续负荷分配，最小化能耗并权衡低负荷。
- **三候选**：B3（能效最优）、bal（低负荷优先，强制每台 ≥0.5 额定）、LRB-t10（限制机组间加载率差 ≤10% 的均衡分配）。
- **安全**：B4 用历史运行点**代理边界**评估喘振裕度，high/unknown 一律阻断并回退。
- **验证**：dev/valid/test 三段 + 全历史统一口径回测；压力用闭环仿真（独立需求+储气质量平衡）在工程假设下验证。

## 3. 五分钟完整汇报（骨架）
1. 背景与目标（≥6% 能效 / ≤±10% 加载率 / ≥99.5% 压力 / ≤60s）；
2. 分工：A 预测/健康 → **B 决策/安全** → C 编排 → D 展示；
3. 方法：B1 基线、B2 模型、B3+bal+LRB、B4 安全、B5 回测；
4. 结果：主方案 LRB-t10 三项同时达标（内部口径），valid/test 单段能效 <6% 如实说明；
5. 工程化：`dispatch_api` 三模式、B01–B20 验收、`simulation` 压力验证；
6. 局限与下一步：官方口径/现场数据/端到端集成。

## 4. 模块简明解释
| 模块 | 一句话 |
|---|---|
| B1 | 固定阈值与优先级的传统人工规则，作公平对照与回退 |
| B2 | 由实测拟合的"流量→功率"工程近似模型，用于 SEC |
| B3 | 枚举 4 种组合 + 最小功率分配的能效优先优化 |
| bal | 需求允许时强制每台 ≥0.5 额定的低负荷优先 |
| LRB-t10 | 限制机组间加载率差的均衡分配 |
| B4 | 代理喘振边界 + 分级 + 阻断 |
| B5 | 同预测/约束/初值的公平回测，区分执行/阻断/不可行 |

## 5. 设计理由与优势
- 先**冻结硬约束**再优化软目标，保证"安全与供气优先于节能"。
- 用 **SEC** 而非总电量，避免"少供气=节能"的假象。
- 三个候选覆盖**能效↔低负荷↔加载率**的 Pareto 前沿，供不同 KPI 权重选择。

## 6. 常见评委问题与参考回答
**Q: 为什么要建立人工基线？** A: 赛题要求"对比人工调度基准"；且 B1 同时作为优化失败时的安全回退，保证任何情况下都有可执行方案。

**Q: 为什么不直接使用历史电耗比较？** A: 历史在不同时间/负荷/供气任务，直接比不公；B5 用**同预测、同约束、同初值、同时长**重放，历史实际单列。

**Q: 为什么采用 SEC？** A: SEC=ΣE/ΣV 对供气量归一，解决"少供气显得省电"的问题；赛题也要求同供气口径。

**Q: 为什么最终选 LRB-t10？** A: 它是唯一**同时**满足 综合能效≥6%（全历史 6.39%）、大马拉小车≥60%（61.8%）、加载率 D3≈100% 的候选，多指标最均衡。

**Q: 为什么 B3 能效更高却不是主方案？** A: B3 SEC 7.94% 最高，但低负荷仅 48.3%（未达 60%）、加载率 D3 0–11%；单指标最优不等于综合最优。

**Q: 压力模型真实吗？** A: B2 压力模型为**工程近似**；实测母管压力近随机游走，一步预测不优于持续性；**反事实不可辨识**，故不作为真实验收依据。

**Q: 为什么压力仿真部分场景没达标？** A: `peak/step/fault` 为**物理容量不足**（需求+5% 备用>2×额定，或单机失效），任何策略都无法维持压力；`normal/low` 无容量受限时合格率 **100%**。

**Q: 什么是喘振？没有厂家喘振线怎么办？** A: 喘振是离心机流量过低导致的失稳；无厂家线时用**历史运行点包络**作**代理边界**，只报代理风险、不宣称真实准确率。

**Q: 高风险时如何保证安全？** A: high/unknown 触发 `safety_blocked`，不自动执行；调度失败一律回退 B1 并再复检供气。

**Q: 为什么 test 单段能效低于 6%？** A: test 需求最高且最窄（均值 472、P95 502），B1 已近最优双机，可优化空间本就小；差距主因是**工况构成**而非算法失效。

**Q: Agent 如何调用 B 组算法？** A: 通过 `dispatch_api.plan_dispatch(mode, snapshot, forecast, health, constraints)`；C 包装为 MCP 工具，B 仅输出 `simulation_candidate_only` 候选。

## 7. 现场演示需解释的关键点
- 三模式切换展示**能效/负荷/压力/安全权衡**；
- 低负荷场景展示"大马拉小车"下降（B1 低负荷 1800 机分钟→优化 15）；
- 设备异常场景展示**安全重分配**与**负例阻断**（容量不足/高喘振）；
- 强调所有结果为**仿真候选**，`execution_permission=simulation_candidate_only`。
