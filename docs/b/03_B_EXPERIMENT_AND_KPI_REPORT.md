## 9. 公式与局限
- 能效：`SEC 降% = (SEC_b1−SEC_x)/SEC_b1×100`；基线为 **B1 规则（内部）**，非官方人工调度。
- 低负荷：`(low_b1−low_x)/low_b1×100`，`low`=运行且 λ<0.5 的机分钟×15。
- 局限：官方无能效公式/加载率定义/压力带；压力与喘振缺真值；端到端需 C 集成。
