## 结论

喘振风险按低/中/高分级；高风险方案不得通过安全校验、不得下发执行。项目使用**机理代理边界**评估，厂家真实喘振曲线缺失。

## 输入

- 实时运行参数（流量、压力、IGV 等）与机理/代理边界配置。

## 输出

- 风险等级与建议；进入调度时 `safety_blocked=true` 表示禁止执行。

## 方法或规则

- 规则与阈值见 `configs/safety.yaml`；高风险的机组方案被安全校验拦截。
- 喘振预警为**代理/工程仿真**，无真实喘振事件标签，不声称准确率。

## 使用方式

```python
from air_station.mcp_servers import tools
tools.surge_warning()
```

## 证据与来源

- `configs/safety.yaml`、`src/air_station/safety/surge.py`

## 适用范围和限制

项目规则与厂家真实喘振线之间存在边界；缺真实喘振数据时的准确率/提前量不可作为现场结论。
