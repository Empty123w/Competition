## 结论

负荷预测使用**梯度提升树（LightGBM）**，对 15/30/60（滚动回放含 45/75）分钟分别训练**独立直接模型**；预测目标为 `target_time` 时刻的**瞬时站级总流量**（m3/min）。

## 输入

- 当前与历史流量、滚动统计、差分、日历/周期特征、环境温湿度、运行机组数等（见特征字典）。
- 运行时入口 `forecast_json(processed_dir, config_path, model_dir, horizons)`。

## 输出

- `predicted_flow`（点预测）、`lower_bound`、`upper_bound`（经验区间），单位 m3/min；
- `prediction_base_time`、`target_time = as_of + horizon_minutes`、`elapsed_seconds`。

## 方法或规则

- 直接多模型，避免递归误差累积；时间顺序切分；`as_of` 之前数据构建因果特征。
- 滚动回放采用扩展窗口、每 7 天重训、每折前 3 个完整自然日做区间校准；区间用**滚动共形**（`pred ± 分位(|残差|, 1-α)`）。
- 不使用未来数据；`forecast_features.parquet` 缺失/为空时返回明确异常。

## 使用方式

```python
from air_station.models.forecasting.service import forecast_json
forecast_json()                      # 默认 15/30/60 分钟
```
