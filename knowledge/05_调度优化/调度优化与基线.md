## 结论

调度优化在满足供气需求、备用容量、加载率与安全/健康约束下，输出开机组合、各机加载率与压力设定；与人工基线对比评估能效、压力稳定性和"大马拉小车"时长。

## 输入

- 需求流量（可由预测给出）、设备能力/性能曲线、约束（压力带、备用、喘振裕度、健康/维护软信号）。

## 输出

- 机组组合与 `device_actions`、预计功率、能效与压力指标；`execution_permission=simulation_candidate_only`，不含真实 PLC 许可。

## 方法或规则

- 多目标：能耗（SEC）/压力稳定性/切换代价；"大马拉小车"指大功率机组长期低负载运行，需被减少。
- **安全回退**：求解失败或安全阻断时回退并标记，需人工复核。

## 使用方式

```python
from air_station.mcp_servers import tools
tools.dispatch_optimize(mode="b3", demand_flow_m3_min=500.0, horizon_minutes=15)
```
