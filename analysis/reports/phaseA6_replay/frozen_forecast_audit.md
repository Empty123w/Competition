## 2. 训练与校准机制（按代码核实）

| 环节 | 实际行为 | 时间范围 |
|---|---|---|
| 数据切分 | `train.py::_split()` 按时间顺序 | train 03-12~07-31；valid 08-01~08-20；test 08-21~09-12 |
| 点模型训练 | 15/30/60 分钟分别直接训练 | 训练基准时刻位于训练段；目标最晚 07-31 23:59 |
| 特征预处理 | 树模型不标准化；滞后/滚动因果 | 环境温湿度曾**双向插值**，为历史回放泄漏风险 |
| 超参数 | 直接读 `configs/forecasting.yaml` | 固定参数与随机种子 42；无 GridSearch/Optuna/早停 |
| 模型类型选择 | 配置优先 LightGBM，依赖不可用回退 | 非按某折验证成绩自动选择 |
| 特征选择 | 配置冻结一组排除字段 | 消融未记录每次选择的数据截止时间（审计缺口） |
| 区间校准 | 验证段残差 5%/95% 分位数写入模型包 | 使用整个 08-01~08-20 验证段 |
| 最终评测 | 加载模型包在测试段评分 | 08-21 起；B5 表为冻结测试产物 |

## 4. 结论（历史回放为何不能复用冻结包）

- 03-12~07-31 时点：冻结点模型已使用其后训练标签，不能回填；
- 08-01~08-20：点模型训练截止在此前，但**区间上下界引用整个验证段残差**；
- 环境字段双向插值可能引用后续最多 30 分钟观测。

因此本次历史回放**独立产出**滚动训练与滚动区间校准，不修改冻结模型，也不覆盖
`forecast_test_predictions.parquet` / `.csv`。
