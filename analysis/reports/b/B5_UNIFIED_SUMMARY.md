## 3. 重点回答
- **bal 在完整历史（dev+valid+test, service_equiv）相对 B1 的 SEC 改善 = 7.50%**（paired 7.73%）。
- **bal 大马拉小车累计时长降低 = 76.0%**（service）/ 77.2%（paired）。
- **test 与 dev/valid 能效差异显著**：test 需求最高且最窄（472/502/510），B1 已近最优双机 → 可优化空间最小（B3 SEC 4.21% vs dev 9.65%、valid 5.62%）。**差距主因是工况构成，非算法失效**（与 `dev_valid_diag.json` 结论一致）。
- **策略优势工况**：
  - **能效（SEC）优先** → **B3** 在 dev 与各段最优（dev 9.65%、pooled 7.71–7.94%）；
  - **低负荷优先** → **bal** 全段 ≥60%（dev 77.0%、valid 81.1%、test 79.3%、pooled 76.0%）；
  - **加载率均衡（机组间 D3）** → **LRB-t10** 全段 99.9–100%（D3），代价 SEC 低于 B3/bal；
  - 三者构成 Pareto 前沿：B3(能效) ↔ bal(低负荷) ↔ LRB-t10(加载率均衡)。
- **主要展示方案建议**：**bal 作为主展示**（pooled SEC 7.50% 且低负荷 76.0%，两项同时位于前列）；**B3** 作能效对照；**LRB-t10** 作加载率专项对照。
