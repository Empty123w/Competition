## 误差可估计性分析 (真实 SCADA)

| 误差来源 | 能否由历史数据估计 | 结果 |
|---|---|---|
| 流量记录量化 | 是 | 记录为浮点, 最小非零差分极小 -> 量化误差可忽略 |
| 站级总流量 vs 两机之和 (双机) | 是 | 残差 p95=0.0 m3/min -> **total 即 f4+f5, 无独立冗余仪表信息** |
| 稳态相邻样本重复性 | 上界 | std(Δf4)=0.61, std(Δf5)=0.75 m3/min -> 折算 σ_D(pp) ≈ 0.32 (含控制抖动, 为上界) |
| 指令-执行跟踪误差 | **否** | 历史数据无 (指令, 实际) 配对 |
| 单一流量计标定误差 | **否** | 无冗余/无标定记录, 无法分离测量误差与工况波动 |
| B2 功率模型误差 -> 流量 | **否** | 残差为功率 kW, 不能直接换算 pp |

**结论: 历史数据不足以确定可靠的工程余量。** 唯一可量化的不确定性 (~0.32pp, 且为上界)
远小于 1pp; 其余关键误差 (执行/跟踪) 不可观测。因此 **不能宣称 9pp 是"有证据的安全余量"**。

## 约束实现核查
- `joint_nompc` 的加载率均衡是**硬约束**: `optimization/unit_commitment.py::best_allocation`
  在枚举中 `abs(f1-f2) <= spread_tol*RATED` 不满足即 `continue` (非软惩罚)。
- 因此实测最大偏离 9.999pp 是 10pp 边界的直接结果, 属**设计行为**。

## 建议
- **保留现 joint_nompc, 不新增"证据性"鲁棒约束** —— 无足够误差数据支撑任何特定余量。
- 若现场执行存在不可观测的跟踪/通信误差, 可将内部阈值降为 9pp 作为**策略性缓冲**
  (实测代价: pooled SEC −0.032pp, 低负荷 +0.35pp, 可行率/供气/安全不变, 时延不变);
  但须明确标注其为**工程策略选择**, 而非由数据推导的安全余量。
- 赛题评价标准 (±10%) 保持不变; 不因余量牺牲供气安全。
