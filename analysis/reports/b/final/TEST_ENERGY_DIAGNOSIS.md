## 7. 结论与主调度方案推荐

**test 节能低主要因为:**
1. 工况高负荷: 均值 472.0 m³/min (0.878×容量), 高负荷(≥90%) 占 0.4326, 低负荷仅 0.0191。
2. **B1 在 test 已高度高效**: B1 SEC 0.090223 (低于 dev 0.106383), 加载率均值 0.8937, <0.5 占比仅 0.0167。
3. 主体负荷带 (400–537.8, 占 test 97%) 中 B1→B3 仅 2.8–4.8% (见 §3)。
4. **模型下界**: test 无约束理想 5.022%、加均衡约束 3.906% → **6% 不可达**。

**joint 在 test 不如 B3 的原因:** 10pp 机组间均衡约束在双机高负荷段强制等分, 400–480 带多用 1.738% 能量、480–537.8 带多用 0.678%; 均衡约束 pooled 代价 1.34 pp。

**推荐主调度方案: `joint_nompc`** (理由见下表)。

| 方案 | pooled SEC降% | valid SEC降% | test SEC降% | 低负荷降% | 偏离度最大pp | 说明 |
|---|---|---|---|---|---|---|
| b3_b4 | 7.707 | 5.441 | 4.125 | 46.606 | 55.359 |  |
| lrb_t10 | 6.385 | 3.568 | 3.038 | 59.1 | 35.581 |  |
| joint_nompc | 7.842 | 3.844 | 2.978 | 69.763 | 9.999 | 同时满足能效/低负荷/加载率 |
| joint | 7.731 | 3.844 | 2.945 | 68.43 | 9.999 |  |

推荐理由: joint_nompc 在 pooled 能效 (**7.84%**, 高于 B3 7.71%)、低负荷 (69.8%, ≥60%)、加载率偏离度 (最大 9.999pp ≤10pp) 三项同时达标, 且复杂度最低; test 单窗口 2.98% 系工况与均衡约束的结构性限制, 非算法缺陷。

**是否需要再修改算法**: 诊断为结构性 (test 高负荷 + B1 已高效 + 均衡约束), 不存在明显多余惩罚项;
建议**主调度=joint_nompc**, 由解析 MPC 独立承担压力控制 (真实平滑窗口 MPC 增量≈0, 仅扰动/容量场景需要);
不建议为抬升 test 数字而放松均衡约束或供气约束; 若未来调参, 应使用开发/验证窗口并另设未见时间段复评。
