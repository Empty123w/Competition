## 3. 建议验证顺序（依赖就绪后）

1. **D1 就绪** → 在 dev/valid 独立窗口复评“分配 + 前瞻”，冻结 dev/valid 结论（不使用 B5 窗口）。
2. **D2/D3/D4 就绪** → 冻结 CAL 口径，**重算基线**（需求/备用/压力），比较口径前后的合规差异。
3. **D5 就绪** → 评估压力设定点方案（离线情景 → 现场阶梯）。
4. **D6 就绪** → 在**全新未使用**窗口做最终评估（B1 vs B3+B4，同任务/同约束）。
5. **D8** → 现场受控验证，报告**现场**电量/SEC/压力/喘振；仅此之后可称“综合能效达标”。

## 4. 现有容量与安全约束下是否存在可验证节能空间

- 冻结 `upper_bound + extra 5%` 下，**98.5% 的共同可行步需求 > 单机额定 268.9 m³/min**，双机刚性运行；当前方案可调手段主要是**负荷分配与机型选择**。
- **口径更正**：B5 的 **3.87% 是当前方案的模型预计节电率**，**不是节能空间上限**；在当前冻结口径下该方案只释放了分配类手段，**理论上限未知、尚未被证明**。
- **压力杠杆**当前不可验证（无响应数据/CAL-05），且冻结模型压力系数符号矛盾。
- 因此**在现有口径与安全约束下，当前方案只能达到约 3.7–4.0%**；要达到 6% 需要额外手段/口径：① 经工程确认的更合理**需求/备用口径**（合规释放单机/低载空间）；② 有证据支撑的**压力设定点下调**；③ 与分配优化组合——均需 D2–D5 支撑，且须经 D6/D8 独立与现场验证。**不声明已达到空间上限。**
