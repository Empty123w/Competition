# B 模块指标字典 (metrics_dictionary_b)

- 负责人：成员 B
- 分支：`feat/b-optimization-aligned`
- 版本：B5
- 口径：所有指标为**模型估计/仿真**；未做现场验证。时间步长 5 分钟（Δ=300 s，时间戳差分核对）。

## 1. 基础量

| 指标 | 符号/单位 | 公式 | 说明 |
|---|---|---|---|
| 步长 | Δ，min | 5 | 采样间隔 |
| 需求气量 | required，m³/min | 预测区间上界 `upper_bound`（CAL-02） | 冻结口径 |
| 计划供气 | plan，m³/min | 策略给出的运行机组流量之和 | 仿真动作 |
| 单机额定 | 268.9 m³/min | 铭牌 | |
| 单机 5% 备用阈值 | 256.095 m³/min | 268.9/1.05 | `extra 5%` 下单机可满足的最大需求 |

## 2. 积分量（独立核对）

| 指标 | 单位 | 公式 |
|---|---|---|
| 电量 | kWh | `E = Σ power_kw × Δ/60`（**不可**把 kW 直接求和） |
| 供气量 | m³ | `V = Σ flow_m3min × Δ` |
| 缺供量 | m³ | `Σ max(required − plan, 0) × Δ`（**仅可行步**） |
| SEC | kWh/m³ | `E / V` |
| 电量降幅 | % | `(E1 − E3)/E1`（同一窗口、同一分母） |
| SEC 改善 | % | `(SEC1 − SEC3)/SEC1` |

## 3. 窗口定义

| 窗口 | 定义 | 分母/样本 | 用途 |
|---|---|---|---|
| `all` | 全窗口 2026-08-21~09-11 | 6325 步 / 527.083 h | 可行率、未评估范围 |
| `common_feasible_preB4` | B1 与 B3 均产出候选（含阻断） | 4735 步 | 主口径之一（B4 过滤前） |
| `b4_retained` | 共同可行 且未被 B4 阻断 | 4712 步 | 主口径之二（含安全过滤） |
| `matched_posthoc` | 共同可行 且 `|Q1−Q3| ≤ 1 m³/min` | 4712/4672 步 | **事后诊断，非主口径** |
| `capacity_infeasible` | 容量不足，无供气 | 1590 步 / 4,128,062.5 m³ | 不可评估 |
| `by_level` | 共同可行按需求三分位 | low/mid/high 各约 1578 步 | 分档 |

> B4 阻断 23 步是 `common_feasible_preB4` 的**子集**，与 `capacity_infeasible` **不重叠**。

## 4. 策略与安全指标

| 指标 | 单位 | 说明 |
|---|---|---|
| 可行率 | % | 该策略在窗口内产出可执行候选的步占比 |
| 逐机启停次数 | 次 | 运行开关状态变化次数（连续回放） |
| 大马拉小车时长 | min | 运行机组 `flow/268.9 < 0.5` 的步数×Δ |
| B4 风险等级 | low/medium/high/unknown | 代理评估，非现场认证 |
| 压力未知状态 | 步 | 历史压力缺失/为 0 的步 |
| 现场可确认量 | — | **本回测一律 unknown**（离线仿真，未经现场确认） |

## 5. 证据类型与限制

| 类型 | 含义 |
|---|---|
| 模型估计 | 由 B2 工程近似功率模型 + 计划流量推算 |
| 历史实测 | `observed_operation`，供气任务可能不同，仅供参照 |
| 代理/仿真 | B4 风险、压力反事实均为仿真，非现场验证 |

- `rated_power_kw=1250` 为铭牌；运行态功率可 >1250（实测有据），**是否属现场允许工况待工程确认**。
- 压力历史测量为**共同初始观测**；B2 不支持动作后反事实压力预测。

## 6. 加载率指标（CAL-04 工程提案, 待 C 确认）

| 指标 | 符号/单位 | 公式 | 说明 |
|---|---|---|---|
| 逐机加载率 | λ | `flow_m3_min / 268.9`（=字段 `load_ratio`） | 等价电流/额定、功率/额定 |
| 目标加载率 | λ* | 设备性能数据推导（非优化器输出） | 口径A=额定 1.0；口径B=逐机效率平台下界(4#0.854/5#0.938) |
| 偏离度 | d，% | `(λ − λ*) / λ* × 100%` | **相对百分比**（非百分点）；负=欠载 |
| 超限比例 | % | `|d| > 10%` 的样本占比 | 目标 ≤ ±10% |
| 超限时长 | min | 超标样本×步长 | 逐机与整体分别报 |

- 适用样本：运行、质量有效、`flow ∈ [120, 268.9]`；排除停机/无效/越界/瞬态。
- **CAL-04 未确认**：口径 A/B 结论差异极大（观测超标 98.8% vs 19.9%），须先确认口径。
- 详见 `load_ratio_definition_b.md`。

## 7. 压力动态与喘振仿真指标

| 指标 | 公式 | 证据类型 |
|---|---|---|
| 压力单步误差 | MAE/RMSE(预测 vs 实测下一分钟) | 模型估计(ARX/persistence) |
| 压力自由多步误差 | k=1..5 步自由仿真 MAE | 仿真 |
| 喘振事件 | `flow < q_true(p)` 连续≥3 s（合成真值线） | 合成秒级仿真 |
| 喘振报警 | B4 `risk∈{medium,high}`；`unknown` 单列 | 代理/仿真 |
| 预警提前时间 | `事件时刻 − 首次报警时刻`，s | 仿真 |
| lead≥30s 覆盖率 | 提前≥30s 的事件占比 | 仿真 |

- 详见 `pressure_dynamics_b.md`、`surge_simulation_validation_b.md`。
