## 3. 关键结论
1. **综合能效 ≥6%（分数据段）**：**开发段达成**（bal 共同 9.40% / 服务等价 8.97%；B3 共同 9.65%）；**验证段未达成**（best B3 5.62%、bal 5.46%）。k0.5 呈现的 7.18% 为**总电量下降**（含降低供气），其 **SEC 仅降 4.94%**，**不算同供气能效**。
2. **大马拉小车 ≥60%**：**bal 达成 81.1%**（验证段），能效 5.61% ≈ B3（−0.11pp）、缺供与 cand 相同、加载率分布与 cand 相当（**验证段非阈值博弈**，均值 0.847、[0.5,0.55) 占比仅 9.7%）。
3. **联合达标需分数据段陈述（更正）**：
   - **开发段（12,284 步）：bal 联合达标** —— 共同口径 SEC 降 **9.40%**（≥6%）、低负荷降 **77.1%**（≥60%）；服务等价 SEC 降 **8.97%**、低负荷降 **74.8%**（同样双达标）。
   - **验证段（1,916 步）：bal 能效未达标** —— 服务等价 SEC 降 **5.46%**（<6%），低负荷降 **81.1%**（≥60%）。
   - **因此不能断言“所有可行算法都无法联合达标”**：bal 在开发段已同时达标；当前证据只能说明**验证段的窄工况下能效 <6%**，二者差异主因是**数据段负荷构成**（见 §6d），而非算法能力极限。
4. **加载率 ±10%**：最好超标 0.23（cand/bal），**未达 ≤10%**；CAL-04 目标口径未定，不能正式判定。
5. **压力 ≥99.5%**：仿真上界钳制主导，**未达标/不可判定**；需 CAL-05 与现场。
6. **调度 ≤60s**：所有候选 p50 ≤35ms、最坏 <1.1s，**满足**。

## 6c. 均衡/加权方法为何无法产出 B3 与 bal 之间的“中间点”（量化）
- 实测（开发段 480 步，固定双机开局）：**当均衡能消除低负荷步时，每步额外能耗几乎恒为 ≈6.75 kWh/步**（均值 26.97 kWh / 4 步，极差 <0.3）；**当均衡不消除低负荷步时，额外能耗 = 0**。
- 因此代价呈**双峰分布**，任何“每步成本阈值”都是**全有或全无**。实测 **SBD 阈值 6 → 7 发生断崖**：低负荷降幅 4.7% → 89.5%（阈值 ≤6 等同 B3，≥7 等同 bal）。
- 结论：**低负荷可实现区间在“步级阈值”下不连续**；中间点只能由**时域加权代价**（cand，w_low=2）产生，且实测 `cand`（开发低负荷 50.6%/SEC 9.60%）被 bal 在低负荷维度支配。这不是“物理上不可优化”，而是**该目标函数在此约束集下的离散结构**。
- 补充：低负荷主要由 **extra 5% 备用**在需求 ∈(256.1, 268.9] 时**强制双机**导致（单机容量 268.9 < need 需求×1.05）；双机后每台 ≈128<134.45。均衡把双机抬到 ≥134.45，需**过供至 268.9**，即为 6.75 kWh/步的来源。

**归因（按贡献排序）**：
1. **负荷构成差异（主因，≈3.4pp）**：开发段可比集含 **27.9%** 步在低负荷区 [0,256)，该区 B1 双机低载（低负荷 51360 min）而优化可单机高效化，**单箱贡献 316,367 kWh（占 65%）**；验证段同区仅 **2.4%** 步。把开发段各箱的**每步**降幅（低负荷区 149 kWh/步、[350,450) 53.6、[450,538) 21.4）按**验证段的箱占比**重加权，重算降幅即回落到 ≈5.4%，与验证段实测 5.46% 一致 → **差距几乎全部由箱占比解释**。
2. **基线能效差异（同源）**：开发段 B1 共通 SEC 0.1063 vs 验证 0.0941，dev 基线更差（因含低负荷双机区），可供改善空间更大。
3. **共享箱的每步降幅几乎相同**：[350,450) dev 8.4% vs valid 8.6%；[450,538) dev 3.2% vs valid 3.5% → **算法在相同工况下表现一致**。
4. **预测上界宽度**：验证段更宽（20.5 vs 11.4），使保守需求略增过供（影响 <0.3pp，次因）。
5. **可行域**：开发段 5.82% 步不可行（obs>2×额定）被 exec_paired 剔除；验证段无 → 不影响可比口径。

**结论**：bal 在验证段能效低 3.94pp **不是算法自适应失败，而是验证段为窄幅高负荷工况（obs∈[400,486]、几乎恒为最优双机运行）**，基线本身已接近高效，剩余可优化空间小。

## 6f. 新算法研究：能量感知均衡 (EAB) 及负结果
- 新增 `src/air_station/optimization/energy_aware_balanced.py`（+单测 `tests/optimization/test_energy_aware_balanced.py`，13 passed）：在“最小能耗方案”与“均衡方案”间按**每步额外能耗上限**切换，目标是在不牺牲低负荷的前提下削减高能耗工况的均衡代价。
- 开发段扫描结果：**cap ∈ {0.5,1,2,5} kWh/步 与 lb ∈ {0.5,0.6} 全部退化为等价于 B3**（低负荷降幅 4.7%），因为**均衡一旦生效其代价恒为 ≈6.75 kWh/步且必然 > 任何小上限**（§6c）。即：**每步成本上限型自适应无法达成 ≥60% 低负荷**。
- 结合 §6c 的双峰结构可得：**在冻结约束下，低负荷 ≥60% 必须接受均衡的固定能耗代价；不存在“低负荷≥60% 且能耗低于 bal”的中间方案**。bal 因此是低负荷目标的 Pareto 最优实现。
- 保留 bal 为当前低负荷最优候选；未发现能同时降低高负荷工况电耗且维持 ≥60% 的新机制。
