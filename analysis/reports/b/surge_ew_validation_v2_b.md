## 1. 真值生成依据与“独立性”说明

- 真值机制：**降低阶压缩机失稳代理**，失稳界限为**独立二次函数** `q_stab(p)=82+300·x−400·x²`（x=p−0.66）。
- 独立性（不止“换个数字”）：
  1. **函数形式不同**：真值为二次，B4 为线性（`90+350·x`）；
  2. **参数来源不同**：真值参数由**独立工程估计**给出，**不复用** B4 配置；
  3. **判定机制不同**：真值=物理流量低于失稳界限并持续；报警=B4 代理边界+触发因子。
- **局限**：仍为**仿真替代**，**非厂家真实喘振线**，**未伪造厂家边界**；真值线参数本身为假设。

## 2. 预先固定的事件/报警/指标定义

| 项 | 定义 |
|---|---|
| 事件 | `flow < q_stab(p)` 连续 ≥3 s |
| B4 报警 | `risk ∈ {medium, high}`；`unknown` 单列，不计报警 |
| EW 报警 | `flow < q_b4(p) + band`，**band=40（当前已选版本，固定）** |
| 事件匹配 | 报警落在 `[事件起点−120s, 事件终点]` 内即检出 |
| 提前量 lead | `事件起点 − 首次不晚于事件的报警时刻`（可负=滞后） |
| **lead≥30s 覆盖率** | 分子=提前≥30s 的检出事件，**分母=全部危险事件（漏报不排除）** |
| 误报小时率 | 不在任何事件窗内的**报警起始次数 / 总小时数** |
| 精确率/召回 | 时间级（报警步 vs 事件步） |

## 3. 验证结果（valid 场景；同一场景同时评 B4 与 EW）

| 指标 | 冻结 B4 | EW (band=40) |
|---|---|---|
| 危险事件数 | 6 | 6 |
| 检出事件（事件级） | 6（recall 1.0） | 6（recall 1.0） |
| **lead≥30s 覆盖率（分母=全部事件）** | **0.0** | **1.0** |
| 精确率（时间级） | 0.9708 | 0.8927 |
| 召回（时间级） | 0.9535 | 0.9535 |
| **误报小时率（次/h）** | **5.143** | **25.143** |
| 报警活跃时间占比 | 0.332 | 0.361 |
| unknown 秒数 | 99 | 0（EW 不产生 unknown） |

- dev 场景（`normal_low / brief_disturb / gradual`）：B4 lead≥30s 覆盖 **0.0**；EW **1.0**，dev 误报小时率 1.333。
- **逐事件 lead** 见 JSON `valid.scenarios[*].{b4,ew}.event_level.leads_s`。

## 4. 关键观察（不夸大）

1. **EW 以更高误报换更高覆盖率**：lead≥30s 由 0→1.0，但**误报小时率 5.1→25.1**、报警活跃占比 33%→36%——存在**过早/持续报警**倾向。
2. **漏报未排除**：覆盖率分母为全部事件；本合成场景中两者事件召回均 1.0，但**不代表现场**。
3. **正常低流量/短暂扰动**场景列入 valid，用于测量误报（未穿越即不应长报警）。
4. **传感缺失**：B4 出现 unknown（99 s），EW 因仅用 flow 阈值仍报警——需注意 unknown 语义差异。
5. band 若再修改，须**另设预先固定的新合成验证场景**（避免用已参与开发的验证集）。

## 5. 结论（第四部分）

- 冻结 B4：**检出可，但提前量不足 30s**。
- 新 EW 层：**仿真下 lead≥30s 覆盖 1.0**，代价是**误报显著上升**。
- **均为合成仿真**：**不得写成准确率达标，也不得写成现场达标**。
- 现场验收需：现场秒级数据 + 厂家喘振边界/真实正例 + 前兆事件标注。
