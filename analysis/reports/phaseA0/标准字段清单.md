# 阶段 A0 交付物：标准字段清单

- 来源依据：阶段 1 报告 `analysis/reports/phase1/`（A–E）与 `data_profile.json`
- 用途：统一站级表与设备级表字段，供后续数据/模型/接口模块对接
- 约定：所有字段**必带单位**；`origin` 取值 `real | inferred | simulated`
- 数据来源标记方式见 `configs/data_quality.yaml` 的 `data_origin`

---

## 0. 键与维度约定

| 约定 | 说明 |
|------|------|
| 时间键 | `time`，`datetime`（本地时间，无时区），频率 60 s，范围 2026-03-12~09-12 |
| 设备键 | `device_number`，整数 ∈ {4, 5}（列名前缀 `4#/5#` 解析而来） |
| 长表结构 | `[time, device_number, indicator, category, value]` |
| 站级表 | `station`，`time` 对齐，站级宽表 |

---

## 1. 站级表字段（station）

## 3. 派生/推断字段（inferred）一览

| 字段 | 单位 | 计算 |
|------|------|------|
| 总流量 | m3/min | 4#+5# 实时流量 |
| 负荷率 | - | 总流量/537.8 |
| 负荷等级 | - | 阈值 0.33/0.67 |
| 波动率_15min / _日级 | - | 见指标释义 |
| 支路流量 | m3/min | = 实时流量 |
| 压差 | MPa | max(排气压力-母管压力,0) |
| 运行 | - | 功率>1kW 或 状态==8 |
| 故障弱标签 | - | 故障码 26 事件段 |
