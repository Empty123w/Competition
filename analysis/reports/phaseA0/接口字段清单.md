# 阶段 A0 交付物：预测与健康接口字段清单

- 用途：定义预测与健康结果的**公共接口**，供后续模块（调度、API、前端、MCP）交接
- 对应实现：
  - 预测：`src/air_station/models/forecasting/service.py`
  - 健康：`src/air_station/models/health/service.py`
- 接口稳定约定：字段名与单位**冻结**，扩展只增不改

---

## 1. 用气负荷预测接口（ForecastResult）

### 1.1 字段定义

| 字段 | 类型 | 单位 | 说明 |
|------|------|------|------|
| generated_at | datetime | — | 结果生成时间（本地时间） |
| horizon_minutes | int | min | 预测时域，取值 {15, 60, 1440} 或自定义 |
| granularity | str | — | 粒度：minute / hour / day |
| model | str | — | 模型标识：naive / seasonal_naive / ridge / hist_gbdt |
| points | array[ForecastPoint] | — | 预测序列 |
| points[].timestamp | datetime | — | 该预测点的时间 |
| points[].value_m3min | float | m3/min | 预测用气总流量 |
| points[].lower | float/null | m3/min | 置信下界（可选） |
| points[].upper | float/null | m3/min | 置信上界（可选） |
| mape | float/null | % | 回测 MAPE（若已评估） |

### 1.2 调用与 JSON 示例

```python
from air_station.models.forecasting.service import forecast, forecast_curve
res = forecast(horizon=15)            # 单点
curve = forecast_curve(horizon=5, step=5, n=6)   # 未来 25 分钟曲线
```

```json
{
  "generated_at": "2026-09-12T00:00:30",
  "horizon_minutes": 15,
  "granularity": "minute",
  "model": "hist_gbdt",
  "mape": null,
  "points": [
    {"timestamp": "2026-09-12T00:15:00", "value_m3min": 431.7, "lower": null, "upper": null}
  ]
}
```

### 1.3 交接约定

- 预测**始终**使用相对路径 `configs/forecasting.yaml` 与 `data/processed/`；
- `horizon_minutes` 决定加载哪个模型 `artifacts/models/forecast_{horizon}.joblib`；
- 未训练时 `service` 会抛 `FileNotFoundError`，调用方需先执行 `train`。

## 2. 设备健康诊断接口（HealthResult）

### 2.1 字段定义

| 字段 | 类型 | 单位 | 说明 |
|------|------|------|------|
| number | int | — | 机组编号 ∈ {4,5} |
| timestamp | datetime | — | 评估时刻 |
| health_index | float | 0~100 | 健康指数（越大越健康） |
| level | str | — | healthy / watch / warning / critical |
| top_indicators | array[IndicatorScore] | — | 贡献最大的指标 |
| top_indicators[].indicator | str | — | 指标名 |
| top_indicators[].value | float | 指标自身单位 | 指标值 |
| top_indicators[].zscore | float | - | 标准化偏离 |
| top_indicators[].contribution | float | 0~1 | 扣分贡献 |
| rul_hours | float/null | h | 剩余寿命估计（当前为 null，待模拟标签） |
| method | str | — | rolling_zscore / isolation_forest |

### 2.2 调用与 JSON 示例

```python
from air_station.models.health.service import health_for, health_all
h4 = health_for(4)
hs = health_all()
```

```json
{
  "number": 4,
  "timestamp": "2026-09-12T00:00:00",
  "health_index": 96.3,
  "level": "healthy",
  "top_indicators": [
    {"indicator": "排气温度", "value": 0.0, "zscore": 0.0, "contribution": 0.12}
  ],
  "rul_hours": null,
  "method": "isolation_forest"
}
```

### 2.3 交接约定

- 健康分级阈值来自 `configs/health.yaml` 的 `scoring.levels`，调用方不得硬编码；
- `rul_hours` 在无模拟/真实标签前**保持 null**，调用方需做空值处理；
- 故障弱标签窗口见 `configs/health.yaml` 的 `fault_weak_labels`，仅用于评估与合理性核对。

## 3. 评价口径对齐（供 C 成员确认）

| 项 | 预测 | 健康 |
|----|------|------|
| 主要指标 | MAPE（目标 ≤ 8%）、MAE、RMSE | 分离度（正常均值-故障均值）、预警提前时间(h)、最低健康指数 |
| 单位 | MAPE %；MAE/RMSE m3/min | 健康指数 0~100；提前时间 h |
| 数据切分 | train 03-12~07-31 / valid 08-01~08-20 / test 08-21~09-12 | 基线拟合 03-12~08-20；核对窗口见故障弱标签 |
| 结果落盘 | `artifacts/metrics/forecast_metrics.json` | `artifacts/metrics/health_metrics.json` |
| 可验证性 | 真实数据闭环，可回测 | 事件级弱验证（故障码 26，样本少） |

> 待确认项：压力合格带（建议 0.55~0.66 MPa）由方案自定义，需与 C 成员一并冻结。
