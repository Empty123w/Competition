## 3. 用气负荷数据.csv（264,961 × 6）— 派生量

| 字段 | 类型 | 单位 | 实测范围 | 缺失率 | 计算口径 |
|------|------|------|----------|--------|----------|
| time | datetime | — | 同上 | 0 | 对齐键 |
| 总流量 | float | m³/min | 0 ~ 597.17 | 0 | `4#实时流量 + 5#实时流量`（已逐行验证一致） |
| 负荷率 | float | 无量纲 | 0 ~ 1.11 | 0 | `总流量 / 537.8` |
| 负荷等级 | int | 类别 | {0,1,2} | 0 | <0.33→0 低谷；0.33~0.67→1 平段；≥0.67→2 高峰 |
| 波动率_15min | float | 无量纲 | 0 ~ 3.87 | 2.4% | `std(总流量,15min)/mean(总流量,15min)` |
| 波动率_日级 | float | 无量纲 | 0 ~ 2.93 | 1.1% | `(当日max−min)/当日mean` |

负荷等级分布：低谷 3.0%、平段 18.7%、**高峰 78.3%**（系统长期高负荷运行）。

## 8. 维护保养记录.xlsx（264,961 × 7）

| 字段 | 类型 | 单位 | 实测范围 | 缺失率 | 异常/说明 |

| time | datetime | — | 同上 | 0 | 对齐键 |

| 5#总运行时间 | float | h | 0 ~ 4314 | 0 | 正常 |
| 4#总负载时间 | float | h | 0 ~ 65535 | 0 | **4# 5,525 行 = 65535** |
| 5#总负载时间 | float | h | 0 ~ 4309 | 0 | 正常 |
| 4#下次保养剩余时间 | float | h | 0 ~ 4.29e9 | 0 | **4# 5,583 行 = 4,294,970,000（哨兵）**；94,732 行 = 0（到期） |
| 5#下次保养剩余时间 | float | h | 0 ~ 1982 | 0 | 正常 |

> 计数器为"距上次保养的周期量"，非终身累计，不单调递增；使用前须清洗哨兵（65535 / 4,294,970,000）。
