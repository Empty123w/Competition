# 阶段 1 交付物 C：可用指标清单（可用真实数据直接计算/验证）

判定原则：指标的分母、分子、标签**全部能由现有真实数据（A 级 + B 级）计算**，无需引入模拟数据。
数值范围均为在 2026-03-12 ~ 2026-09-12 全量 264,961 分钟数据上实测所得，可直接作为**基准值（baseline）**。

---

## 1. 可直接计算的运行/能效指标

| 指标 | 定义与公式 | 数据来源 | 实测基准（示例） |
|------|-----------|----------|------------------|
| 机组实时流量 | 单机 `实时流量` | 设备运行参数 | 4# 均值 197.7、5# 均值 230.0 m³/min |
| 总流量 | `4#实时流量 + 5#实时流量` | 用气负荷（可自算） | 均值 427.7、最大 597.2 m³/min |
| 负荷率 | `总流量 / 537.8` | 用气负荷 | 均值 0.795、最大 1.11 |
| 负荷等级 | 按 0.33/0.67 分档 | 用气负荷 | 低谷 3.0% / 平段 18.7% / 高峰 78.3% |
| 单机比功率 | `功率 / 实时流量`（运行态） | 运行参数 | 4# 均值 5.34、5# 均值 5.51 kW/(m³/min) |
| 系统比功率 | `Σ功率 / 总流量` | 运行参数 | 可直接计算 |
| 机组/系统有功功率 | 单机 `功率`，系统求和 | 运行参数 | 4# 均值 1082、5# 均值 1240 kW |
| 机组运行/停机占比 | `功率>1kW` 占比 | 运行参数 | 4# 83.2%、5# 97.0% |
| 母管压力波动幅度 | `std(母管压力)` 或 `max−min` | 管网 | std 0.051 MPa |
| 压力合格率 | `合格点数 / 总点数`（阈值需甲方给定，如 0.55~0.66 MPa） | 管网 | 阈值确定后即可算 |
| 排气压力-母管压差 | `max(排气压力−母管压力,0)` | 管网/运行参数 | 已验证口径 |
| IGV 开度分布 | 单机 `IGV开度` 分布 | 运行参数 | 均值 78.4% / 81.5% |
| BOV 闭度分布 | 单机 `BOV闭度` 分布 | 运行参数 | 均值 80.5% / 94.2% |
| 加卸载频次（推断） | 由 IGV/BOV/功率阶跃反推 | 运行参数 | 需定义阈值，可算 |
| 启停次数（推断） | 由 `功率` 0↔正 反转推 | 运行参数 | 可算 |
| "大马拉小车"识别 | `功率>阈值 且 负荷率<阈值` 的分钟数 | 运行参数 | 基准时长可算 |
| 波动率（15min/日级） | 现成字段 | 用气负荷 | 均值 0.013 / 0.585 |

## 2. 用气负荷预测类（可回测验证）

| 指标 | 验证方式 | 数据来源 |
|------|----------|----------|
| 分钟级负荷预测 MAPE ≤ 8% | 用真实 `总流量` 做滚动回测（train/test 切分，如 03-12~07-31 训练、08-01~09-12 测试） | 用气负荷 / 用运行参数自算 |
| 小时级负荷预测 MAPE | 同上，重采样到小时 | 同上 |
| 日级负荷预测 | 按日聚合回测 | 同上 |

> 结论：**负荷预测的三个时间尺度都可用真实数据回测**，是全项目最扎实的可验证能力。

## 3. 供气品质/稳定性类（可验证）

| 指标 | 验证方式 | 数据来源 |
|------|----------|----------|
| 供气压力合格率 | 定义合格带后统计占比 | 管网母管压力 |
| 压力波动幅度 | 对比"基准调度 vs 优化调度"仿真 | 管网压力 + 管网模型 |
| 压力越限时长 | 统计越限分钟数 | 管网压力 |

> 注意：合格带需**甲方或方案自行定义**（数据未提供合格阈值）。定义后即为可验证指标。

## 5. 可作为"基准值"直接固化的量（用于后续对比）

这些量用**真实历史数据**算出，作为人工调度基准（baseline），后续优化方案与之对比即得"提升/x下降"类指标：

| 基准量 | 值 |
|--------|-----|
| 系统比功率基准 | 由真实功率/流量计算 |
| 母管压力波动 std 基准 | 0.051 MPa |
| "大马拉小车"时长基准 | 由阈值规则统计 |
| 单位时间综合电耗基准 | `Σ功率 × Δt` 累计 |
| 4#/5# 运行占比基准 | 83.2% / 97.0% |
| 加卸载/启停频次基准 | 由运行参数反推 |

> 用法：优化调度策略"减少 X%"或"提升 Y%"的**分母来自真实基准**，分子来自仿真/优化结果。这样"幅度类"指标可在真实基准上验证，风险点仅在"分子"是仿真值。

## 5. 运行状态与故障事件类（v2 新增，真实可用）

| 指标 | 定义与公式 | 数据来源 | 实测基准 |
|------|-----------|----------|----------|
| 机组运行/停机状态 | `状态==8` 为开启、`==10` 为关闭 | 运行事件记录 | 与功率>1kW 一致率 99.1% / 99.9% |
| 运行时长 / 停机时长 | 按状态累计分钟 | 运行事件记录 | 4# 停机 46636 min、5# 停机 7848 min |
| 启停次数 | 状态 8↔10 切换次数 | 运行事件记录 | 可直接统计 |
| 故障事件识别（事件级） | `故障!=0` 的连续段 | 运行事件记录 | 4# 5 段、5# 2 段；故障码恒 26 |
| 故障持续时长 | 各故障段分钟数 | 运行事件记录 | 4# 最长 18433 min、5# 最长 15612 min |
| 故障与运行状态耦合 | 故障期间状态分布 | 事件+状态 | 故障期间仍多处于开启 |

> 局限：故障码仅 1 种（26），且 4#/5# 故障高度同步（03-19 起、04-13 止），疑似**站级共因事件**；可作为"故障/正常"二分类与事件检测的**弱标签**，不足以训练多类故障模型或支撑 90% 准确率类指标的统计置信。

## 6. 维护保养类（v2 新增，需清洗哨兵）

| 指标 | 定义与公式 | 数据来源 | 实测基准 |
|------|-----------|----------|----------|
| 累计运行时间 | `总运行时间`（清洗 65535 哨兵后） | 维护保养记录 | 4# ~2966h、5# ~2133h |
| 累计负载时间 | `总负载时间`（清洗后） | 维护保养记录 | 4# ~2962h、5# ~2128h |
| 距下次保养剩余时间 | `下次保养剩余时间`（清洗后） | 维护保养记录 | 5# 均值 478h；4# 大量 0（到期） |
| 保养到期提醒 | 剩余时间 ≤ 阈值 | 维护保养记录 | 可直接实现 |
| 保养窗口推算 | 结合设备档案保养周期（4000/8000/24000h） | 维护记录+档案 | 可推算 |

> 清洗规则：剔除 `65535`、`≥4.29e9` 哨兵；注意计数器非单调递增，按周期量语义使用。5# 数据干净，4# 需清洗。

---

## 7. 小结

**完全可验证（真实数据闭环）**：
1. 用气负荷预测（分钟/小时/日）MAPE
2. 系统/单机比功率、功率、流量、负荷率等能效刻画
3. 母管压力波动、压力合格率（阈值定义后）
4. 运行/停机状态识别、启停次数、运行时长（v2 升级为显式状态）
5. **故障事件检测与持续时长（事件级弱验证，v2 新增）**
6. **累计运行/负载时间、保养到期提醒（v2 新增）**
7. 系统性能时延类指标
8. 所有"优化前基准值"

这些构成了项目所有"对比型指标"的**可信分母**。
