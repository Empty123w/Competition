## 6. 新增数据质量评估

### 6.1 运行事件记录（264,961 × 9）

| 字段 | 可用性 | 实测 |
|------|--------|------|
| `4#状态` / `5#状态` | **可用** | 8=开启、10=关闭；与功率>1kW 一致率 99.09% / 99.90%；另有 ~88/131 行噪声值（如 7.01、8.5）可忽略 |
| `4#加卸载` / `5#加卸载` | **不可用** | **整列全空（264,961 行全 NaN）** |
| `4#预警` / `5#预警` | **不可用** | **恒为 0**，无任何预警记录 |
| `4#故障` / `5#故障` | **部分可用** | 故障码恒为 **26**，块状出现；4# 5 段、5# 2 段 |

故障事件明细（故障码 26）：

| 机组 | 时间段 | 时长 |
|------|--------|------|
| 4# | 2026-03-19 15:30 ~ 03-20 09:18 | 1,069 min |
| 4# | 2026-03-31 19:35 ~ 04-13 14:47 | 18,433 min |
| 4# | 2026-04-21 / 04-22 / 08-09 短事件 | 1~2 min |
| 5# | 2026-03-19 15:34 ~ 03-20 09:18 | 1,065 min |
| 5# | 2026-04-02 18:36 ~ 04-13 14:47 | 15,612 min |

> 关键判断：4#、5# 的故障**同时开始（03-19 15:30/15:34）、同时结束（04-13 14:47）**，呈强同步性，更像**站级共因事件**（如系统停气、PLC/仪表事件、计划停机），而非两台机器独立故障。故障期间状态仍多为"开启"，与"故障停机"语义不符。

### 6.2 维护保养记录（264,961 × 7）

| 字段 | 可用性 | 实测 | 异常 |
|------|--------|------|------|
| 4#/5#总运行时间 | 可用（清洗后） | 4# 均值 2966h、5# 均值 2133h | **4# 有 5,524 行 = 65535（uint16 溢出哨兵）** |
| 4#/5#总负载时间 | 可用（清洗后） | 4# 均值 2962h、5# 均值 2128h | **4# 有 5,525 行 = 65535** |
| 4#/5#下次保养剩余时间 | 可用（清洗后） | 5# 均值 478h | **4# 有 5,583 行 = 4,294,970,000（进位出错/哨兵）**；4# 另有 94,732 行 = 0（保养已到期） |

- 计数器**非单调递增**（是"距上次保养的周期量"而非终身累计），需按语义使用。
- 5# 三项均正常（≤4314h / ≤1982h）。

## 9. 故障与维护记录是否足以训练模型（更新）

| 数据项 | v1 | v2 | 结论 |
|--------|----|----|------|
| 运行/停机状态 | 推断 | **显式（可用）** | 可做状态识别、启停/运行时长统计 |
| 故障标志 | 无 | **有（故障码 26，事件级）** | 可做"正常/故障"事件检测，但**仅 1 种故障码、事件极少且疑似共因**，不足以训练多类故障模型 |
| 预警记录 | 无 | **无（恒 0）** | 预警准确率/提前时间仍无法验证 |
| 加卸载记录 | 无 | **无（列全空）** | 加卸载频次仍只能由 IGV/BOV/功率反推 |
| 维护保养记录 | 无 | **有（含哨兵）** | 可推算保养窗口，但 4# 计数器需清洗 |
| 环境参数 | 有（错位文件） | **有（v3 已恢复）** | 站房温湿度可用于环境修正、冷却与喘振环境因素 |
| RUL 标签 | 无 | 无 | 仍无法直接验证 RUL |

**结论**：v2 使"运行状态"和"故障事件"从无到有，故障类指标从"完全不可验证"升级为"**事件级弱验证**"（可演示检测及时性，但样本量与故障种类不足以支撑 90% 准确率类指标的统计置信）。维护记录补齐使维保决策可落地。喘振边界、环境参数、加卸载、预警仍缺，相应指标继续走机理/模拟。

## 10. 数据质量分级（v3）

| 等级 | 数据 | 用途 |
|------|------|------|
| A 级 | 设备运行参数、设备状态监测、设备档案、**环境参数** | 负荷预测、能效、调度仿真、趋势分析、环境修正 |

| C 级（缺/需模拟） | 加卸载、预警、性能曲线、喘振边界、RUL、多类故障 | 对应指标以机理/模拟替代并显式声明 |
